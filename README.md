# 📚 Tabela de Faltas da Vivi

Bem-vindo ao projeto **Tabela de Faltas da Vivi**! Este site foi criado para facilitar o controle de faltas nas disciplinas, ajudando estudantes a acompanharem sua frequência de forma simples, visual e prática.

## ✨ Funcionalidades

- Visualize todas as matérias, faltas atuais, limite de faltas, faltas restantes, % de faltas e % de presença.
- Aumente ou diminua o número de faltas em cada disciplina com apenas um clique.
- As faltas são salvas automaticamente no navegador (localStorage), então você não perde seus dados ao recarregar a página.
- Interface moderna, responsiva e fácil de usar.
- Ícone personalizado na aba do navegador.

## 🚀 Como usar

1. Faça o download ou clone este repositório:
   ```bash
   git clone https://github.com/seu-usuario/seu-repositorio.git
   ```
2. Abra o arquivo `index.html` em qualquer navegador.
3. Use os botões `+` e `-` para ajustar o número de faltas em cada matéria.
4. Pronto! Suas faltas serão salvas automaticamente.
